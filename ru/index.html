Часто задаваемые вопросы

Откуда берутся данные?

Все данные о приёмах поступают непосредственно из официального API Национального фонда здоровья Польши (NFZ), доступного по адресу api.nfz.gov.pl/app-itl-api/. Данные получаются в реальном времени, поэтому вы всегда имеете доступ к новейшей информации о доступных приёмах.

Насколько актуальны данные?

Приложение получает данные в реальном времени из API NFZ при каждом поиске. Нет необходимости в ручном обновлении - данные всегда актуальны. Вы можете потянуть вниз, чтобы повторно получить новейшие данные.

Почему я не могу найти конкретное учреждение?

Отображаются только учреждения, зарегистрированные в NFZ и принимающие пациентов по медицинскому страхованию. Частные учреждения не включены в базу данных NFZ.

Как записаться на приём?

Приложение показывает доступные приёмы и контактную информацию. Чтобы записаться, позвоните непосредственно в учреждение с помощью кнопки телефона в приложении.

Какие опции сортировки доступны?

Вы можете сортировать результаты по: первой доступной дате, расстоянию от вашего местоположения, времени ожидания или размеру очереди. Выберите опцию сортировки из меню на экране результатов.

Сохраняет ли приложение историю поиска?

Да, приложение сохраняет историю ранее искавшихся названий услуг. Вы можете быстро выбрать из истории или удалить отдельные записи.

Приложение бесплатное?

Да, приложение полностью бесплатное. Нет скрытых платежей или подписок.
